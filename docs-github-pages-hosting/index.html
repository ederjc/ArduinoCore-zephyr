Arduino Core for Infineon PSOC™

This project brings Arduino support to selected Infineon boards powered by Zephyr. See Supported Boards for an overview of currently supported boards.

Looking for Arduino support for other Infineon microcontrollers? See:

  • PSOC™ 6 for Arduino

  • XMC™ for Arduino

Architecture

Unlike native Arduino cores (e.g. for AVR or SAMD boards), where the Arduino APIs talk almost directly to the microcontroller, this core runs on top of Zephyr RTOS. Zephyr provides the kernel, drivers, devicetree-based build system, and board support; the Arduino Core for Zephyr exposes those capabilities through familiar Arduino APIs.
